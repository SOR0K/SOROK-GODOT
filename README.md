# SOROK — 고도(Godot 4) 판

SOROMA GAMES · 외계 기지 정복 전략. 웹 SOROK을 고도 엔진으로 옮기는 프로젝트예요.

## 패드에서 여는 법 (파일 하나)
`scripts/game.gd` 하나로 돌아가요. 고도에서 2D 씬(Node2D) → 스크립트 붙이기 → 내용을 이 파일로 전부 바꾸기 → ▶

## 여는 법 (PC)
1. GitHub Desktop으로 이 저장소를 받아요 (Clone → 이후엔 **Pull** 한 번이면 최신으로)
2. 고도 4.7 → **가져오기** → 받은 폴더의 `project.godot` 선택
3. ▶ 실행 (F5)

## 조작 (1단계)
| | PC | 패드·폰 |
|---|---|---|
| 화면 이동 | 왼쪽 드래그, WASD/방향키 | 한 손가락 드래그 |
| 확대·축소 | 마우스 휠 | 두 손가락 벌리기·오므리기 |
| 로봇 선택 | 클릭 (Shift+클릭: 추가) | 탭 |
| 같은 종류 전체 | 더블클릭, 숫자 1~5 | 더블탭 |
| 여러 대 묶기 | 오른쪽 드래그 | 꾹 누른 뒤 끌기 |
| 전체 선택 | 기지 클릭 | 기지 탭 |
| 이동 명령 | 땅 클릭 | 땅 탭 |
| 미니맵 | 클릭·드래그로 이동 | 탭·드래그 |
| 기지로 | Space / Home | 미니맵 |

정찰 로봇만 암흑을 밝히고, 다른 로봇은 밝혀진 칸으로만 길을 찾아가요 (웹과 같아요).
